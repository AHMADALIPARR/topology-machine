# Contributing

Topology Machine is AGPL-3.0-only. Contributions to the project source are made under that license. Do not add a copyright line that names a person who is not already identified by the change itself; the tree uses “Topology Machine contributors” because the starter named none.

## Scope

Keep the models finite and the claims matched to the tests. A change that widens a model should say what is still not proved.

Do not add packet capture, raw sockets against a real network, interface shutdown, or a claim that GF arithmetic or `O_APPEND` is a MAC or a WORM log. See `docs/REFERENCE_BOUNDARY.md`.

Klong scripts that are part of the comparison must be executed by `third_party/klong/kg` and diffed with C output. A Python translation of those scripts is not a substitute. Do not relicense files under `third_party/klong/`.

## Build

```sh
make test
make test-san
```

`make test-san` uses `SAN_CC`, default `gcc`, because a Clang without compiler-rt cannot link ASan. New C should build with `-Wall -Wextra -Werror -pedantic` and with ASan/UBSan.

Golden QASM and SMT files are byte comparisons with the starter. Change them only when the emitted text is intentionally different, and say why.

Figures in `assets/` are generated by `make assets` from `make bench` output. If you change a command’s stdout, regenerate the transcript renders and do not describe them as photographs.

## Tests worth adding with a behavior change

- A malformed input that must return a nonzero status.
- If the change is a field, gate, or amplitude identity, an exhaustive check on the finite domain when the domain is at most a few tens of millions of points.
- If the change is a Klong result, a line in `klong/oracle.kg` and the same line from `tm oracle`.
